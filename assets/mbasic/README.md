# Microsoft BASIC-80 5.21

`MBASIC.COM` is the unchanged CP/M binary archived as `MBASIC5.COM` at:
https://deramp.com/downloads/microsoft/CPM%20Software/MBASIC5.COM
Its startup identifies BASIC-80 Rev. 5.21, CP/M Version, Microsoft 1977-1981,
created July 28, 1981. Only the host filename has been changed.
It is installed on E:. It is historical Microsoft software, not original
project code or part of the public-domain BDS C release.

SHA-256: `29d957fc6899c24f6296a1662a27eca545d85ee3f7d70d2794c9d045d92ff157`

The build manifest records the installed binary and example checksums.
