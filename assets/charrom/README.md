# P2000M character ROMs

Copied unchanged from `ifilot/p2000m-emulator` at commit
`ecabb2b9411c08cd21ac0fdc415ff63c5309246f`, directory `assets/charrom`.
These recovered P2000M glyphs contain scanlines 0–7 (upper) and 8–11 (lower)
for 256 characters. Historical firmware retains its original rights.

Used by the optional screenshot and boot-preview renderers. Firmware builds
and headless regression tests do not need a renderer or Pillow.
