P2000M web emulator

This is a web-based emulator of the Philips P2000M with the CP/M co-board, the P2000M SD CP/M cartridge in port 1 and the SD/SRAM cartridge in port 2. It boots the same cartridge ROM and SD-card image as the latest build, entirely in your browser.

Click the screen to use your keyboard. The P2000M has no Ctrl key: CP/M control characters are typed as Esc followed by a letter, and Esc Esc sends Escape itself. Your Ctrl combinations are translated automatically, so Ctrl+C works as expected. You can also paste text into the display.

The twelve drives include Microsoft BASIC-80 and COBOL-80, BDS C, SuperCalc2, Zork I–III and Othello. Changes you make are kept until you reload the page; drive L: is a RAM disk that Reset erases.

Using CP/M

Type a command at the A> prompt and press Enter. Upper or lower case both work.

DIR DIR J:
List the files on the current drive or on another drive.
C:
Switch to drive C:. The prompt changes to C>.
HELLO J:OTHELLO
Run a program by typing its name without .COM, with a drive prefix if it lives elsewhere.
TYPE E:BASDEMO.BAS
Show a text file. MORE shows it one page at a time.
PIP L:=E:BASDEMO.BAS
Copy a file, here to the RAM disk. REN renames files and ERA erases them.
STAT HELP
Show free disk space, or the built-in quick reference.

Try C: then ZORK1, D: then SC2 for SuperCalc2, or E: then MBASIC BASDEMO; type SYSTEM to leave BASIC. Ctrl+C at an empty prompt restarts CP/M.
