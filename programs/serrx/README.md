# SERRX

Receives paced RS232 bytes at 300 baud, 8N1, and displays them in hexadecimal.
Intended to verify input polarity and framing; it is not a buffered receiver
for continuous streams.

Run `B:SERRX`; press Q to quit. See the
[serial test guide](../../docs/serial-testing.md) for the paced PC sender.
