# Firmware images

This directory contains the preserved firmware distributed with the M2000
project:

The monitor is common to the P2000T and P2000M. Selectable cartridge and disk
images are organized under `../software/`; see `../software/README.md`. The image is
included for historical preservation and interoperability. Philips retains any
rights it may have in the original firmware.
